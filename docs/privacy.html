Политика конфиденциальности Spark Edu

Последнее обновление: 2026-05-06

1. Термины и определения

  • Spark Edu — образовательная платформа, включающая веб-интерфейс и Telegram-бота.
  • Разработчик — команда Spark Edu, обеспечивающая поддержку и развитие сервиса.
  • Сторонний сервис — Telegram-бот @spark_edu_bot, используемый для отправки уведомлений.
  • Пользователь — лицо, привязавшее свой аккаунт Spark Edu к Telegram-боту.

2. Сбор персональных данных

Мы собираем только минимально необходимый набор данных для обеспечения работы сервиса уведомлений:

  • Telegram Chat ID: уникальный идентификатор вашего чата для технической возможности отправки сообщений.
  • User ID: идентификатор вашего профиля Spark Edu, передаваемый через защищенный токен (JWT) при регистрации.
  • Предпочтения по категориям: данные о подписках на типы контента (напр. code, language).

3. Обработка и использование данных

Ваши данные обрабатываются исключительно в следующих целях:

  • Модерация: уведомление автора о результатах проверки контента AI-системой (Llama 3.3).
  • Рассылки: оповещение о выходе новых лекций в выбранных вами категориях.
  • Техподдержка: идентификация пользователя при возникновении технических проблем.
Мы не продаем и не передаем ваши персональные данные третьим лицам для рекламных или маркетинговых целей.

4. Защита и хранение

  • Все данные хранятся в защищенной базе данных PostgreSQL.
  • Доступ к данным ограничен и осуществляется только через защищенные внутренние API-запросы.
  • При удалении подписки или отвязке бота данные о связи профиля с Telegram удаляются из системы безвозвратно.

5. Права пользователя

Вы имеете полное право:

  • В любой момент отозвать согласие, удалив бота или отвязав аккаунт на сайте.
  • Запросить информацию о хранящихся данных через команду /help или /developer_info.
  • Требовать полного удаления информации (право на забвение).
